# Screenshots

README images live here so the GitHub page matches [Roblox Fastflag Manager](https://github.com/4anti/Roblox-Fastflag-Manager): a hero shot, then a two-up showcase.

The `.svg` files are stand-ins. When you have captures from the running app:

1. Save them as:
   - `picker.png` (main window, empty or with a few items)
   - `list.png` (close-up of the queue)
   - `splash.png` (the `--launch` overlay)
2. In `README.md`, change those three `src=` paths from `.svg` to `.png`.
3. Keep width about 800px for the hero and 450px for the showcase cells.

A 1080×640 window at 100% scaling is enough. Crop the desktop out if you can.
