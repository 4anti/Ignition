# Security Policy

## Supported versions

Only the latest published release receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| unreleased | :white_check_mark: |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository.

When reporting, include:

- The affected version (`package.json` / `src-tauri/tauri.conf.json`).
- A clear description and steps to reproduce.
- Logs or screenshots where they help.

You should expect an initial acknowledgement within seven days.
